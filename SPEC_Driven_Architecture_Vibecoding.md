# Spec-Driven Architecture para ResearchHub-U

Fuente de verdad tecnica del proyecto. El documento completo original esta en
`docs/specs/SPEC_Driven_Architecture_Vibecoding.original.md`.

Reglas operativas para este repositorio:

- Implementar solo requisitos `BASE` o `APROBADO`.
- Tratar requisitos `PROPUESTO` como sujetos a validacion.
- No inventar reglas funcionales del proceso de homologaciones.
- Registrar desviaciones arquitectonicas con ADR en `docs/adr/`.
- Mantener trazabilidad entre requisito, codigo, prueba y cambio.
