# ResearchHUB

## Producto operable

Antes de modificar codigo, API, datos, seguridad, infraestructura, pruebas o
despliegue, lee y aplica
`.dev/skills/researchhub-production-engineering/SKILL.md`, `CONSTRAINTS.md` y el
spec afectado. No agregues cuentas demo, claves compartidas, datos semilla durante
requests ni afirmes que una version esta lista para produccion sin la evidencia de
`.dev/PRODUCT_READINESS.md`.

## Identidad UCompensar

Antes de crear o modificar interfaces, estilos, texto visible, imágenes, documentos o presentaciones, lee y aplica `.dev/skills/ucompensar-look-and-feel/SKILL.md`.

Los activos maestros y la guía consolidada están en `.dev/brand`. El Brandbook 2026 prevalece ante contradicciones con plantillas históricas.

Verifica todo cambio visual en escritorio y móvil, con contenido realista, accesibilidad WCAG AA y consola del navegador sin errores inesperados.
